# trk  
A task tracker for those of us with ADHD.  

## Core Idea  
I regularly slip into accidental rabbit holes when working on things.  
I'll be setting up an LXC container in order to run a Gitea action 
runner, and in doing so I'll need to install Node, but the standard
documentation isn't working in my setup so now I need to figure that
out. I was installing node because the action workflow step said no 
node was installed.  

This is a super simplified, and honestly not great example, but 
you should get the idea. My ADHD tends to forget the "bigger picture"
very quickly, and that's where `trk` comes in!  

`trk` is (err... will be) designed specifically to make it easy to
track what it is you're working on and ultimate get back to the top
of the tree, indicating you've actually completed a thing!  

At least, that is what I hope.
